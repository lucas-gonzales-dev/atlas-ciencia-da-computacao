O Atlas está carregando.

Se esta frase continuar na tela, o navegador não executou ./web/casco.js. Isso acontece quando o index.html é aberto com duplo clique, pelo protocolo file:// — que bloqueia módulo. Sirva por http: na pasta do projeto rode node app/serve.js e abra http://localhost:41730/.

Abriu por http e a tela continua vazia? É cache antigo deste app: recarregue com Ctrl+Shift+R, ou abra F12 → Application → Service Workers e desregistre.
